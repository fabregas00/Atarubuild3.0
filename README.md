# Ataru

Ataru is a self-contained mobile-first wellbeing and learning prototype for children.

## Run locally

Open `index.html` in a modern browser. No build, package installation, or server is required.

## Included features

- Child onboarding, parent dashboard placeholder, language controls, and local profile import
- Sequential four-chapter learning path with quiz gates
- Local progress, streak, mood check-ins, text/voice journal, breathing activity, and mini game
- Light/dark themes and responsive interface

## Data

This prototype uses browser `localStorage` only. It does not send data to a server.
